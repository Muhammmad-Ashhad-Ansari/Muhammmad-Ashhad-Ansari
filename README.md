## 🔐 Featured Project — SecureAuth

### Human-Centered Two-Factor Authentication

**SecureAuth** is a security-focused 2FA web application designed around
both **Information Security** and **Human-Computer Interaction principles**.

It combines TOTP authentication with a clear and accessible user
experience.

### ✨ Highlights

- 🔑 Password + TOTP Two-Factor Authentication
- 📱 Authenticator App Integration
- 🛡️ CSRF Protection
- 🚫 Brute-Force Protection
- 🔄 TOTP Replay Prevention
- 🔐 Secure Session Management
- 🆘 Backup Recovery Codes
- 📊 Security Dashboard
- 🌗 Light & Dark Modes
- ♿ Accessibility Features
- 🎨 Human-Centered Security UI
- 🚀 Live Deployment
